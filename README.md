# Mi Cliente — Sitio web

Página de presentación de Mi Cliente (mi-cliente.vercel.app). Sitio estático
(HTML + CSS, sin build), separado del código de la app.

## Publicar en Vercel

1. Entra a vercel.com con tu cuenta.
2. "Add New" → "Project" → "Import Git Repository".
3. Elige este repositorio (`mi-cliente-web`).
4. Framework Preset: "Other" (no necesita build). Deja todo lo demás por defecto.
5. Deploy — en menos de un minuto queda con su propia dirección `algo.vercel.app`.

Cuando compres un dominio propio, lo agregas en Project Settings → Domains de ese mismo proyecto.
